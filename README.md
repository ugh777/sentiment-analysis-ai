# Sentiment Analysis AI

A simple, end-to-end machine learning project that classifies text reviews as **positive** or **negative** using a TF-IDF + Logistic Regression pipeline (scikit-learn).

This repo is structured as a template for AI/ML projects — feel free to swap in your own dataset and model.

## Project Structure

```
sentiment-analysis-ai/
├── README.md              # Project overview (this file)
├── requirements.txt       # Python dependencies
├── LICENSE                # MIT License
├── .gitignore              # Files/folders excluded from git
├── configs/
│   └── config.yaml         # Hyperparameters & file paths
├── data/
│   ├── raw/                 # Original, unmodified dataset
│   └── processed/           # Cleaned data (generated by scripts)
├── models/                 # Saved trained models (git-ignored)
├── notebooks/
│   └── exploration.ipynb    # Optional EDA notebook
├── src/
│   ├── data_loader.py        # Load & clean the dataset
│   ├── train.py               # Train the model
│   ├── evaluate.py            # Evaluate model performance
│   └── predict.py             # Run predictions on new text
└── tests/
    └── test_model.py          # Unit tests
```

## Setup

```bash
git clone https://github.com/<your-username>/sentiment-analysis-ai.git
cd sentiment-analysis-ai
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

**1. Train the model**
```bash
python src/train.py
```

**2. Evaluate the model**
```bash
python src/evaluate.py
```

**3. Predict on new text**
```bash
python src/predict.py --text "I absolutely loved this product!"
```

## Example Output

```
Text: "I absolutely loved this product!"
Prediction: Positive (confidence: 0.93)
```

## Dataset

A small sample dataset (`data/raw/reviews.csv`) is included so the project runs out of the box.
Replace it with your own labeled dataset (columns: `text`, `label`) to train on real data.

## Running Tests

```bash
pytest tests/
```
